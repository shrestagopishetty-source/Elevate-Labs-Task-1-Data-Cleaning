# Elevate Labs Task 1 – Data Cleaning & Preprocessing

## Objective
To clean and prepare raw data for machine learning using Python.

## Dataset
Titanic dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
1. Loaded and explored the dataset.
2. Checked and handled missing values.
3. Encoded categorical features using one-hot encoding.
4. Standardized numerical features using StandardScaler.
5. Detected and removed outliers using the IQR method.
6. Saved the cleaned dataset as `Titanic_Cleaned.csv`.

## Files
- `Elevate_Labs_Task_1_Data_Cleaning.ipynb` – Complete notebook
- `Titanic_Cleaned.csv` – Cleaned dataset

## Conclusion
The Titanic dataset was cleaned and preprocessed for use in machine learning.
